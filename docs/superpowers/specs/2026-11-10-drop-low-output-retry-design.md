# 取消低产出重试（第十轮补充）

日期：2026-11-10
状态：待确认

## 意图

预分析分块在同一份内容上重试一次，只为把低产出块救回来。重发的提示词与首次几乎相同（只在末尾多一句「Return ONLY the JSON array.」），而低产出通常源于文章本身难点少，重采样很难让条目数量翻倍；即便不重试，低产出结果也会保留（全部块都低时整篇仍标 ready）。因此低产出重试基本只多花一次模型调用。

## 目标

- 低产出块不再重试，直接按现状保留其条目。
- 解析失败仍重试一次（截断、格式错误可能因采样不同而恢复，且没有其他补救）。
- 模型调用失败仍不重试。

## 非目标

- 不改提示词措辞，不改分块大小，不改低产出阈值。
- 不改全块低产出时保留并标 ready 的既有行为。

## 方案

`_run_with_retry` 的触发条件从「解析失败 或 条目数低于下限」改为「仅解析失败」。下限仍由 `_analyse_chunk` 计算并传入，判定失败后照常抛 `LowOutputError`，由 `analyze_article` 收集保留并记 warning。

## 影响

- `tests/test_analyze.py` 中依赖「低产出会重试」的 4 个断言改为期望 1 次调用。
- 新增一个回归测试：首次解析失败、第二次成功时仍应重试并成功。
- `analyze_snippet` 传入 `min_items=0`，行为不变。

## 代价

极少数「模型这次确实答少了」的情况失去第二次机会；该块内容会以低密度结果保留，并通过 warning 日志可见。

## 验证

`uv run pytest`、`uv run ruff check .`、`uv run mypy` 全绿。
